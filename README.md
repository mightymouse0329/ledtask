# robomaster-stage-one：RoboMaster C 板基础功能

本工程基于 RoboMaster 开发板 C 型（STM32F407IGH6）：STM32CubeMX 配置外设，STM32 HAL + FreeRTOS 运行任务，CMake 构建。已实现并通过实物验证的功能包括：启动提示音、RGB 流水灯、IMU 六轴串口输出、DT7 遥控器通信、双 GM6020 电机与 C 板姿态联动、手动输入联动和箭头复位。分阶段的操作与排查记录见 `docs/`。

## 一、功能与效果

| 功能 | 效果 |
| --- | --- |
| 启动提示音 | 上电或复位后依次播放 1000、1500、2000 Hz 三声，各约 120 ms、间隔约 60 ms，播放一遍后停止 |
| RGB 流水灯 | 板载 RGB 按红 → 绿 → 蓝循环渐亮渐暗，占空比 0 % → 50 % → 0 %，每步约 1 %、30 ms |
| 心跳监测 | 默认任务每约 20 ms 更新心跳；LED 任务每约 500 ms 检查，超时则暂停渐变并保持 15 % 红色 |
| IMU 串口输出 | USART1 约每 50 ms 输出一行：遥控器状态 + BMI088 三轴加速度与三轴角速度 |
| 遥控器通信 | 接收 DT7/DR16 的 DBUS 数据，解析四个通道与左右拨杆；失联约 100 ms 后回到失能状态 |
| 姿态联动 | 右拨杆中档：A 电机与 C 板 yaw 以 1:1 联动，B 电机比例由左拨杆选择（下 0.5、中 −1、上 3），并带参考角速度前馈 |
| 手动输入联动 | 人工转动其中一台电机时识别为输入源：该台输出为零，另一台按比例跟随，松手后保持新位置不回零 |
| 箭头复位 | 右拨杆上档：两台电机箭头转回与当前 C 板箭头同向，到位后继续位置保持 |

电机上电默认零输出（锁定）；右拨杆先置下档、再切到中档或上档才解锁，并在解锁瞬间记录箭头对齐基准。

## 二、硬件与外设

- 开发板：RoboMaster 开发板 C 型，STM32F407IGH6，系统时钟 168 MHz
- 电机：两台 GM6020 接 CAN1，A 为 ID 1、B 为 ID 2，1 Mbit/s；电流指令帧 0x1FE，反馈帧 0x205 / 0x206
- 传感器：板载 BMI088，SPI1（PB3=SCK、PB4=MISO、PA7=MOSI、PA4=加速度计片选、PB0=陀螺仪片选）
- 遥控器：DT7 手柄 + DR16 接收机，DBUS 经板上反相电路进入 PC11（USART3）
- 串口：外壳 UART2 四针口（芯片内部为 USART1，TX=PA9、RX=PB7），115200、8N1、无流控
- 下载器：OpenOCD + CMSIS-DAP，配置见 `openocd.cfg`

| 器件 | 引脚 | 定时器通道 |
| --- | --- | --- |
| 蜂鸣器 | PD14 | TIM4_CH3 |
| 蓝色 LED | PH10 | TIM5_CH1 |
| 绿色 LED | PH11 | TIM5_CH2 |
| 红色 LED | PH12 | TIM5_CH3 |

CAN 总线两端各接 120 Ω 终端电阻，电机与 C 板共地。电机 ID 用拨码设置：A 为第 1 位 ON、第 2/3 位 OFF；B 为第 1 位 OFF、第 2 位 ON、第 3 位 OFF。**第 4 位是终端电阻开关，不是 ID**，不要两台同时打开。

## 四、编译与烧录

```bash

cmake --build --preset Debug
openocd -f openocd.cfg -c "program build/Debug/robomaster-stage-one.elf verify reset exit"
```

## 五、操作说明

### 拨杆与模式

| 右拨杆 | 模式 | 说明 |
| --- | --- | --- |
| 下 | 零输出 | 上电、失联和故障后都回到这里，也是解锁的起点 |
| 中 | 姿态联动 | 左拨杆选择 B 电机比例：下 0.5、中 −1、上 3 |
| 上 | 箭头复位 | 忽略左拨杆，两台电机对齐 C 板当前方向 |

摇杆平时不参与控制。台架测试模式（恒速转动测试、开环电流测试）默认关闭，需要时把 `applications/control_constants.hpp` 中的 `MOTOR_BENCH_TEST_MODES` 设为 `true`。

### 首次上电

1. 断电接线：电机固定、运动范围空旷，右拨杆置下档；
2. **手动把 C 板与两台电机的箭头对齐**，C 板保持水平；
3. 上电后保持静止约 5 秒，直到串口第 10 列显示 `30`（IMU 就绪）；
4. 右拨杆在下档保持约 1 秒，再切到中档或上档——解锁并记录对齐基准；
5. 联动时缓慢转动 C 板即可看到电机跟随，上档可让箭头复位。

出故障后输出自动清零并锁定，需把右拨杆拨回下档再重新解锁。若对齐基准失效（IMU 掉线或电机反馈异常），重新对齐箭头、回下档再切档即可重新记录，无需重启。

## 六、串口数据格式

115200、8N1、无流控、文本模式；每行 16 列，约 50 ms 一行，无表头：

| 列 | 内容 |
| --- | --- |
| 1–2 | 接收机在线、armed |
| 3–4 | 右拨杆、左拨杆（1 上 / 2 下 / 3 中） |
| 5 | 请求模式（0 失能 / 1 联动 / 2 复位） |
| 6–9 | 四个摇杆通道（右水平、右垂直、左水平、左垂直，约 −660~660） |
| 10 | IMU 状态码，`30` = 就绪 |
| 11–13 | 加速度 X / Y / Z（m/s²，静止平放时含重力） |
| 14–16 | 角速度 X / Y / Z（°/s） |

示例：`1,1,2,2,0,0,0,0,0,30,0.012,-0.025,9.800,0.061,-0.122,0.000`

逐轴倾斜或转动可核对三轴方向与符号。发生故障时串口会额外输出 `FAULT_HISTORY_BEGIN/END` 包围的故障前快照，字段带名字，便于排查。

## 七、主要参数

参数集中在 `applications/control_constants.hpp`，修改后重新编译烧录。

| 参数 | 当前值 | 说明 |
| --- | --- | --- |
| 位置环 Kp / Ki / Kd | 9.0、10、0.1 | 位置误差 → 目标转速，积分权限 0.5 rad/s |
| 速度前馈 | 1.0 | 参考角速度直接加到速度指令，消除匀速跟踪的固有滞后 |
| 速度环 Kp / Ki | 0.02、0.6 | 转速误差 → 电流，积分上限 0.30 A |
| 目标转速上限 / 斜率 | 90 rpm、300 rpm/s | 按 1:3 比例档定尺寸 |
| 电流限幅 | 0.45 A（约 0.33 N·m） | 高于 GM6020 的静摩擦阈值，避免低速粘滑 |
| 超速停机 | 200 rpm，连续 10 个控制周期（约 20 ms） | 联动与复位；恒速测试模式单独使用 150 rpm |
| 过温保护 | 60 ℃ | 任一电机超过即停机锁定 |
| 复位到位判据 | 误差 ≤ 1.2°、速度 ≤ 0.08 rad/s，持续 1 s | 30 s 未到位报故障 |
| 复位接近速度 | 20 rpm | 进入复位时目标最多相差 180°，故单独限速 |
| 手动输入判据 | 偏离 1.2° 持续 60 ms | 静止 500 ms 后退出接管 |

## 八、已知限制

- C 板 yaw 由陀螺仪积分得到，只适用于近似水平、绕竖直轴旋转的场合，静止时会有缓慢漂移；没有磁力计融合。
- 零电流指令不等于电机完全无阻力：GM6020 在零电流时相间等效短路，仍有阻尼。
- 已取消行程保护，联动与复位时需自行保证机械活动空间与线缆余量。
- 电机上电默认锁定，必须先在右拨杆下档确认，再切档解锁。
