# 第八步：统一操作与箭头复位

本页描述当前程序。此前阶段文档中的编译开关和单电机 10° 实验属于历史方案，当前无需修改 ENABLE 开关或换固件来切换模式。功能尚未经过实物验证。

## 首次上电操作

1. 断电接线，确认电机固定、运动范围空旷，确认 CAN ID、供电和电机控制协议匹配。当前使用 CAN1、A ID1、B ID2、电流指令 0x1FE。
2. 上电前手动对齐 C 板与两台电机箭头，电机底座保持固定；C 板保持水平。右拨杆置下档。
3. 上电后保持三个箭头对齐且静止，等待 IMU 预热和静态校准，通常至少约 5 秒；串口应显示 YAW 有效、两台电机反馈有效。
4. 保持右拨杆下档，确认三个箭头已对齐后，将右拨杆切至中档或上档。程序在数据健康时立即记录对齐基准并解锁。观察 CONTROL 的 calibrated=1、unlocked=1、fault=0。RC 的 ready/armed 只代表遥控器条件，不能替代 CONTROL unlocked。
5. 右拨杆保持下档时输出为零；切至中档或上档后进入对应运动控制。解锁时会记录当前箭头对齐基准，因此切换前必须确认三个箭头对齐。

## 同一程序中的模式

| 右拨杆 | 当前行为 |
| --- | --- |
| 下档 | 发送零电流指令；上电时等待解锁动作，故障后回到下档重新准备 |
| 中档 | C 板 yaw 与 A 以 1:1 联动；B 比例由左下 0.5、左中 -1、左上 3 决定；参考角速度同时作为速度前馈（匀速跟踪误差接近 0）；包含手动转动电机的识别与参考点更新 |
| 上档 | **复位**：两台电机箭头朝向当前 C 板箭头方向，忽略左拨杆比例，完成后继续位置保持。台架测试模式默认关闭，需要时见文末 |

摇杆不参与本任务。进入各模式首个周期先发送零输出并建立参考。上档保持期间若 C 板继续转动，复位目标也会随之改变；判断对齐效果时先保持 C 板不动。

## 复位的原理与边界

程序保存对齐时的 yaw 和两个编码器角度。复位目标为初始电机角度加上 C 板相对初始的 yaw 变化，并按电机方向修正。进入复位时选择相差不超过 180° 的等效目标，再缓慢靠近；不是无条件回到编码器零值。

初始对齐基准与手动联动的参考点分别保存，手动拖动不会覆盖对齐基准。算法假设两台电机底座固定、旋转轴与 yaw 方向对应；底座转动或其他安装结构需要重新分析。程序不能看见箭头，对齐基准依赖操作者确认。

当前到位条件为两电机角度误差均不超过约 1.2°、速度均不超过 0.08 rad/s，持续 1000 ms，此时 RESET done=1。done 之后控制器仍在继续修正，误差会继续收敛；若箭头看着仍有偏差而误差列接近 0，那是机械侧（背隙/箭头安装）而不是控制问题。这是待调试参数，不代表赛事已验收合格。上档仍会保持位置，done 不表示电机失能。连续 30 秒未到位将报故障并锁定。运动限幅和跟踪误差保护仍然生效。

复位有自己的接近速度上限 `MOTOR_RESET_MAX_TARGET_SPEED_RAD_S`（20 rpm = 120°/s）：进入复位时目标可能离当前位置最多 180°，用联动的 90 rpm 上限会以 540°/s 冲过去，因此单独限速，最坏半圈约 1.5 秒走完。到位状态用常规串口第 26 列的位判断：1=对齐基准有效、2=正在复位、4=已到位并稳定（例如 `6` 表示正在复位且已到位）。

## 串口观察与故障恢复

- CONTROL：unlocked 解锁状态，mode 0 下档 / 1 联动 / 2 复位，calibrated 对齐基准有效，fault 首个故障。
- RESET：active 是否正在复位，done 是否满足到位条件，settled_ms 到位持续时间，zero_yaw / zero_A / zero_B 为保存的基准（弧度）。
- LINK：目标角度、渐变参考和输出；MANUAL：手动输入来源；YAW / CAN / 电机反馈用于排查数据问题。
- fault：1 电机反馈、温度或速度异常；2 IMU 不可用；3 遥控器；4 CAN；5 控制周期；6 运动范围或跟踪误差；7 手动输入冲突；8 复位基准不可用或超时。
- 上电校准期间可能暂时显示故障；程序保留首次故障，健康后先回右下档，再切至中档或上档即可重新解锁。故障发生时输出置零并重新锁定。
- calibrated=1 时保留原始对齐基准；calibrated=0 时解锁时记录当前基准，因此切换前必须重新确认三个箭头对齐。
- IMU 或电机累计角度失效会清除对齐基准。部分历史失效会锁存，须排除原因、断电重新对齐后重启。基准只在 RAM 中，重启后必须重新确认。

## 到学校仍需完成

无需为下档、中档、上档反复修改程序。首次实物调试仍需核对并可能修改 control_constants.hpp 中的电机 ID、正方向、增益和限幅；不能靠软件自动判断接线、控制模式和安装方向。请先检查通讯和下档，再逐项检查小角度联动、手动输入和复位。

零电压指令不保证电机完全无阻力，必须实测是否满足比赛“无力”要求；当前手动输入采用误差与速度推断，不能可靠区分手动拨动和外部干扰。C 板 yaw 来自陀螺仪积分，要求近似水平，漂移会表现为静止时目标缓慢变化、复位箭头逐渐偏离。硬件到手后记录串口输出和现象再调参。

当前仅完成软件实现与后续编译检查，不代表硬件验收。24V 转 5V PCB 设计也属于独立的未完成事项。

## 恒速转动测试（mode=3，默认关闭的台架模式）

> 默认关闭：只有把 `MOTOR_BENCH_TEST_MODES` 设为 `true` 才能用"上档+左拨杆上档"进入；交付映射下右拨杆上档一律进入复位。

实验开始前用它确认电机能不能转。不进位置环，也不用于比赛运行。

1. 固定机构，确认可以持续旋转或只用几秒钟观察；准备好随时断电。
2. 右下档解锁，然后右拨杆上档、左拨杆上档，进入 mode=3；常规串口第 1 列显示 3。
3. 控制器用编码器速度环把两台电机稳在 15 rpm（`MOTOR_SPIN_TEST_TARGET_RAD_S`），命令走 0x1FE 电流帧，沿用联动内环的速度 PID 与 `MOTOR_CURRENT_LIMIT_A` 限幅。
4. 判据：
   - 第 11/17 列转速稳定在 15 rpm 附近、第 13/19 列角度持续变化 → 电机、编码器、电流通道都正常；
   - 第 10/16 列反馈电流跟随请求（第 9/15 列）但转速仍为 0 → 电流到位而轴不转，属于堵转：查机械卡死、机构限位、负载过大或电机型号/减速箱差异；
   - 第 10/16 列也接近 0 → 命令没有进入电机，用左下档的开环电流测试继续判断。
5. **不使用 GM6020 电压帧 0x1FF**：实测 1.5 V 电压命令下两台电机电流几乎为 0、完全不转，而同一时刻电流帧工作正常，因此该通道不再使用。
6. 该模式的超速上限是 90 rpm（其他模式仍为 30 rpm）；离线、反馈过期、过温和 CAN 检查仍然生效。退出后等转速接近 0 再切到联动或复位。

## 开环电流测试（mode=4，默认关闭的台架模式）

> 默认关闭：只有把 `MOTOR_BENCH_TEST_MODES` 设为 `true` 才能用"上档+左拨杆下档"进入；交付映射下右拨杆上档一律进入复位。

用于把"力矩不足 / 电流帧没有生效 / 电机或机械卡死"三种情况分开，不用于比赛运行。

1. 断电接线，电机固定、运动范围空旷，准备随时断电；上电后按首次上电操作保持右下档。
2. 右拨杆置上档、左拨杆置下档，进入 mode=4；常规串口第 1 列显示 4。
3. 缓慢上推左摇杆（回中即零输出），对照每台电机的"电流请求 / 反馈电流 / 反馈转速"三列：
   - 请求上升而反馈电流几乎不动 → 电流指令没有进入电机，查 ID、接线、终端电阻与供电，或用电压控制型号对照；
   - 反馈电流跟随请求但转速一直为 0 → 电流到位但力矩不足以克服摩擦或负载；
   - 转速开始变化并随后出现 fault=1、原因位 32 → 电机与电流通路正常，只是触发 30 rpm 超速保护，可以回到联动去整定参数。
4. 该模式两路电机电流同号同值；上限 ±0.60 A，远高于联动使用的 ±0.15 A，因此**只用于诊断**。
5. IMU 不参与本模式（电机动作导致水平判定失败不会中断测试），但进入模式时 IMU 仍需处于 READY。
6. 开环下自由电机会迅速加速并触发超速停机，属于预期现象；超速判据现在要求连续 10 个控制周期（约 20 ms）越限。
