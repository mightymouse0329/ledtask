# 第八步：统一操作与箭头复位

本页描述当前程序。此前阶段文档中的编译开关和单电机 10° 实验属于历史方案，当前无需修改 ENABLE 开关或换固件来切换模式。功能尚未经过实物验证。

## 首次上电操作

1. 断电接线，确认电机固定、运动范围空旷，确认 CAN ID、供电和电机控制协议匹配。当前使用 CAN1、A ID1、B ID2、电流指令 0x1FE。
2. 上电前手动对齐 C 板与两台电机箭头，电机底座保持固定；C 板保持水平。右拨杆置下档。
3. 上电后保持三个箭头对齐且静止，等待 IMU 预热和静态校准，通常至少约 5 秒；串口应显示 YAW 有效、两台电机反馈有效。
4. 保持右拨杆下档，确认三个箭头已对齐后，将右拨杆切至中档或上档。程序在数据健康时立即记录对齐基准并解锁。观察 CONTROL 的 calibrated=1、unlocked=1、fault=0。RC 的 ready/armed 只代表遥控器条件，不能替代 CONTROL unlocked。
5. 右拨杆保持下档时输出为零；切至中档或上档后进入对应运动控制。解锁时会记录当前箭头对齐基准，因此切换前必须确认三个箭头对齐。

## 同一程序中的模式

| 右拨杆 | 当前行为 |
| --- | --- |
| 下档 | 发送零电流指令；上电时等待解锁动作，故障后回到下档重新准备 |
| 中档 | C 板 yaw 与 A 以 1:1 联动；B 比例由左下 0.5、左中 -1、左上 3 决定；包含手动转动电机的识别与参考点更新 |
| 上档 | 两台电机箭头朝向当前 C 板箭头方向，忽略左拨杆比例；完成后继续位置保持 |

摇杆不参与本任务。进入各模式首个周期先发送零输出并建立参考。上档保持期间若 C 板继续转动，复位目标也会随之改变；判断对齐效果时先保持 C 板不动。

## 复位的原理与边界

程序保存对齐时的 yaw 和两个编码器角度。复位目标为初始电机角度加上 C 板相对初始的 yaw 变化，并按电机方向修正。进入复位时选择相差不超过 180° 的等效目标，再缓慢靠近；不是无条件回到编码器零值。

初始对齐基准与手动联动的参考点分别保存，手动拖动不会覆盖对齐基准。算法假设两台电机底座固定、旋转轴与 yaw 方向对应；底座转动或其他安装结构需要重新分析。程序不能看见箭头，对齐基准依赖操作者确认。

当前到位条件为两电机角度误差均不超过约 2°、速度均不超过 0.04 rad/s，持续 500 ms，此时 RESET done=1。这是待调试参数，不代表赛事已验收合格。上档仍会保持位置，done 不表示电机失能。连续 30 秒未到位将报故障并锁定。运动限幅和跟踪误差保护仍然生效。

## 串口观察与故障恢复

- CONTROL：unlocked 解锁状态，mode 0 下档 / 1 联动 / 2 复位，calibrated 对齐基准有效，fault 首个故障。
- RESET：active 是否正在复位，done 是否满足到位条件，settled_ms 到位持续时间，zero_yaw / zero_A / zero_B 为保存的基准（弧度）。
- LINK：目标角度、渐变参考和输出；MANUAL：手动输入来源；YAW / CAN / 电机反馈用于排查数据问题。
- fault：1 电机反馈、温度或速度异常；2 IMU 不可用；3 遥控器；4 CAN；5 控制周期；6 运动范围或跟踪误差；7 手动输入冲突；8 复位基准不可用或超时。
- 上电校准期间可能暂时显示故障；程序保留首次故障，健康后先回右下档，再切至中档或上档即可重新解锁。故障发生时输出置零并重新锁定。
- calibrated=1 时保留原始对齐基准；calibrated=0 时解锁时记录当前基准，因此切换前必须重新确认三个箭头对齐。
- IMU 或电机累计角度失效会清除对齐基准。部分历史失效会锁存，须排除原因、断电重新对齐后重启。基准只在 RAM 中，重启后必须重新确认。

## 到学校仍需完成

无需为下档、中档、上档反复修改程序。首次实物调试仍需核对并可能修改 control_constants.hpp 中的电机 ID、正方向、增益和限幅；不能靠软件自动判断接线、控制模式和安装方向。请先检查通讯和下档，再逐项检查小角度联动、手动输入和复位。

零电压指令不保证电机完全无阻力，必须实测是否满足比赛“无力”要求；当前手动输入采用误差与速度推断，不能可靠区分手动拨动和外部干扰。C 板 yaw 来自陀螺仪积分，要求近似水平，漂移会表现为静止时目标缓慢变化、复位箭头逐渐偏离。硬件到手后记录串口输出和现象再调参。

当前仅完成软件实现与后续编译检查，不代表硬件验收。24V 转 5V PCB 设计也属于独立的未完成事项。
