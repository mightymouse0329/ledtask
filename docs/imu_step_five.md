# 第五步：IMU 水平相对 yaw 与问题排查

## 1. 已实现什么

先初始化BMI088 → 等待3秒 → 连续静止校准至少2秒和400帧 → 将此时yaw记作0 → 角速度扣零偏 → 用实际采样间隔积分 → 串口显示。

采样与打印已分成两个任务：imu_task负责读取和计算，每次等待5ms，实际间隔含读取和调度耗时；telemetry_task负责串口，约每500ms显示IMU/YAW。当前不是硬件同步的精确200Hz采样，也没有使用DRDY/FIFO。位置、遥控器等打印继续保留，电机运动默认关闭。

校准用三轴原始角速度均值当零偏。瞬时绝对值不超过3°/s、整个候选窗口每轴极差不超过0.8°/s，并满足水平和加速度条件才继续累计；不满足会重来。约5秒是顺利情况下的量级，不是必定完成的期限。门限是本阶段初始选择，不是厂家合格标准。

慢速匀速转动可能通过这些条件，因此程序只能判断“静止候选”，必须由你保证真正静止。不要在手上拿着校准。

## 2. 重要适用范围

本阶段是**正面朝上、基本水平的相对yaw积分**，不是完整三维姿态解算。ACC只用于静止/姿态条件检查，没有融合成roll、pitch、yaw。大幅倾斜时，机体Z轴角速度不再等同于地面参考系的yaw角速度。

水平检查要求加速度模长与9.80665m/s²相差小于1m/s²，且Z正分量与模长之比大于0.94。这个门限约对应20°，只是拒绝明显倾斜的初始条件，不代表倾斜20°仍保证准确；实验时应尽量水平。平移加速、碰撞或振动也可能使它不通过，不能只凭LEVEL_OR_ACCEL判断传感器损坏。

校准结束时的朝向是0°，不是正北，也不是上电瞬间的朝向。yaw连续累计，可以超过360°，不会在±180°跳变。正方向取决于传感器Z轴，实物方向仍要核对。

没有磁力计、外部角度参考、恒温控制；预热等待3秒不保证温度稳定，也不能彻底消除漂移。不要看到READY就认为所有硬件已通过验收。

## 3. 上板后先怎样操作

1. 保持MOTOR_POSITION_ENABLE=false，先单独观察IMU。
2. C板正面朝上，平放在稳定桌面，连接现有串口：115200、8N1、无流控、文本模式。
3. 上电/复位，暂时不移动，观察WAIT→WARMUP→CALIBRATING→READY。
4. 确认valid=1、reason=NONE、io=1，samples持续增加，io_errors不持续增长。
5. 先静置60秒保存日志，再水平缓慢转约90°，停止后观察，再转回原方向。不要一开始就晃动、翻面或快速旋转。
6. 出现FAULT时先保存错误前后的日志。确认情况后复位并重新平放校准；不要反复复位却不记录现象。

## 4. 串口怎么看

以下只是示例，不是实测：

```text
IMU READY valid=1 reason=NONE level=1 io=1 cal=401/400 restarts=0 init_error=0
YAW t_ms=6000 deg=0.0200 rate_deg_s=0.0300 bias_z_deg_s=0.1200 dt_ms=5 max_dt_ms=6 age_ms=1 samples=1100 io_errors=0 gaps=0
ACC X=0.010 Y=-0.020 Z=9.800 norm=9.800 | GYRO X=0.010 Y=-0.010 Z=0.150
```

### IMU行

- WAIT：初始化尚未完成或正在重试。
- WARMUP：初始化完成后的3秒等待。
- CALIBRATING：在收集静止数据。
- READY：校准完成，可以观察本阶段yaw。
- FAULT：yaw当前不可信。校准后已经检测到的故障锁定到复位，不偷偷重新设零。
- valid：yaw当前是否满足本程序条件；0时yaw可能是最后可信的旧值，不可用于控制。
- reason=SPI：校准后SPI读取失败。
- reason=GAP：相邻成功采样间隔达到20ms，或打印快照发现数据已过期。可能是调度、断点、阻塞等，未必硬件损坏。
- reason=LEVEL_OR_ACCEL：倾斜、翻面、加速或振动使本阶段条件不成立。
- reason=RANGE：非有限数值、角速度接近量程边界等异常。
- level：本程序的平放/重力条件，不是精密倾角值。
- io：最近一次读取是否成功；FAULT时io也可能恢复为1，但旧yaw不能因此恢复可信。
- cal：本轮校准收集帧数；可能超过400，因为还需满足至少2秒。
- restarts：校准窗口重新开始的次数；晃动或间隔异常会增加。
- init_error：0=无当前初始化错误，1=SPI，2=加速度计ID，3=陀螺仪ID，4=加速度计配置，5=陀螺仪配置。当前读取失败不一定产生非零init_error，要同时看io_errors。

### YAW行

- t_ms：这份快照最后成功采样的上电时间，单位毫秒。
- deg：校准完成以来累计的yaw，单位度。
- rate_deg_s：Z轴原始角速度减去校准零偏后的值，单位度/秒；静止时应接近0，但不会每次精确为0。
- bias_z_deg_s：启动静止校准得到的Z轴零偏，本次运行保持固定，没有偷偷跟随变化。
- dt_ms：相邻成功读取的实际间隔，正常应在5ms附近，未实测，不保证恰好5。
- max_dt_ms：自启动以来最大间隔，包含初始化重试等历史，不是当前瞬间的间隔。
- age_ms：取得快照时的数据年龄，不是文字到达电脑时的延迟。
- samples：成功读取计数；若长期不增，要结合其他打印判断采样是否停止。
- io_errors：初始化或读取失败累计次数。
- gaps：在尚未锁定FAULT前发现的长采样间隔次数，不用于统计故障后的全部丢帧。

ACC单位m/s²，含静止重力响应。正面朝上平放时X/Y应接近0、Z应接近+9.8，模长接近9.8；具体安装方向需核对。GYRO仍是未扣零偏的三轴角速度，单位°/s，所以GYRO Z与rate_deg_s不同是正常的。

## 5. 怎么发现漂移

**漂移：板子实际没转，yaw却持续朝一个方向变化。** 小幅来回抖动和单向持续变化要区分。

平放不动，READY后记录t_ms和deg，等60秒再记录。计算：

漂移速度（°/分钟）=（后一次deg−前一次deg）÷时间差（秒）×60。

例如0.2°变成3.2°，耗时60秒，就是约+3°/分钟。若rate_deg_s长期平均偏+0.05°/s，理论上约产生+3°/分钟的累计误差；这是解释用算例，不是允许误差或合格标准。

本程序不会把小角速度强制裁成零，也不会自动把yaw拉回零，所以漂移会真实显现在deg中。将来联动若直接使用漂移的yaw，可能表现为C板没动而电机慢慢走；当前尚未接入yaw联动，因此当前电机现象不能直接归因于该yaw。

启动几分钟后漂移变化，可能与温度变化、启动校准条件有关；要记录“刚上电”和“运行几分钟后”的同样静置段，不能只发最后一张截图。当前没有采集温度曲线，尚不能凭这些信息单独确定温漂。

## 6. 现象与排查方向

| 现象 | 先记录和检查 | 能否直接认定硬件坏了 |
| --- | --- | --- |
| 静止yaw小幅抖动 | rate均值是否接近0、是否桌面振动 | 不能，可能是噪声 |
| 静止yaw单向慢慢变化 | 60秒漂移、bias、运行时长、校准时是否移动 | 不能，可能残余零偏/温度/算法 |
| 转90°显示明显不是90° | 起止差值、是否平放、dt、方向、转动速度 | 不能，先查轴向、时序、比例和实验方式 |
| 一直CALIBRATING | level、cal是否归零、restarts、ACC与GYRO、gaps | 不能，先放稳及检查门限/方向 |
| 初始化错误持续重复 | init_error、供电、板型、SPI配置 | 可能是连接/配置/硬件，需要逐项排查 |
| 突然FAULT GAP | dt、max_dt、调试器是否暂停、其他任务阻塞 | 常是时序问题，非硬件损坏证明 |
| FAULT LEVEL_OR_ACCEL | 倾斜、翻面、平移冲击、ACC模长 | 多为超出当前算法条件 |
| samples不增但RC/CAN仍打印 | IMU任务/驱动阻塞、SPI错误 | 采样链路问题，先看日志 |
| 所有文字都停止 | COM口、无线链路、供电、复位、断点、整机停机 | 不能只定位到IMU |
| 电机OFFLINE | CAN接线、ID、供电、终端电阻、frames/errors | 与IMU是另一条链路 |
| 电机不动且POSITION enabled=0 | 默认关闭设置 | 正常行为，不是电机损坏 |
| 电机实验开启后抖动或跑偏 | 立即停止，记录方向、out_raw、位置/速度、故障 | 可能控制方向或参数，勿直接加大增益 |

上面的阈值是排查线索，不是赛事合格线。尚未确定比赛允许的yaw误差，所以不虚构“每分钟小于几度必定合格”。

## 8. 文件与边界

imu_yaw.cpp/.hpp负责校准、积分、状态和快照；imu_task.cpp内imu_task负责采样，telemetry_task负责打印。FreeRTOS两个任务在USER CODE区创建，无需在CubeMX任务列表再重复创建。未新增测试用例或执行硬件测试，编译状态见README。

BMI088由三轴加速度计和三轴陀螺仪组成，参考 [Bosch官方数据手册](https://www.bosch-sensortec.com/media/boschsensortec/downloads/datasheets/bst-bmi088-ds001.pdf)。陀螺仪噪声、零偏会造成积分姿态漂移，加速度计的重力方向不能独立约束yaw，参考 [VectorNav姿态原理](https://www.vectornav.com/resources/inertial-navigation-primer/theory-of-operation/theory-ahrs)。本次没有实现完整AHRS或磁航向校正。
